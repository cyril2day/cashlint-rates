# Cashlint Rates

Cashlint Rates is a greenfield Next.js App Router application for educational exchange-rate conversion, analysis, and comparison.

This first implementation milestone establishes the project spine:

- strict TypeScript configuration;
- functional `Result`, `Maybe`, and `AsyncResult` primitives;
- handwritten request decoders;
- standard API envelope mapping;
- protected source boundaries through ESLint;
- a sample currency catalogue route, service, and domain test.

Internal planning folders are ignored by git in this checkout and should stay out of remote pushes.

## Commands

```bash
pnpm install
pnpm lint
pnpm typecheck
pnpm test
pnpm dev
```
